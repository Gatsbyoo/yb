# 小日子

一个给自己人用的手机小工具集合。**纯前端，没有后端、没有账号、没有广告**，所有数据存在使用者的手机浏览器本地，离线也能打开。

线上地址：<https://gatsbyoo.github.io/yb/>
（手机上打开后「添加到主屏幕」，就是一个全屏的独立 App）

---

## 目录

```
index.html            小日子（根目录 = 主应用）
css/style.css         设计系统 + 全部样式（含深色模式）
js/core.js            存储 / 日期 / 抽屉 / 轻提示等基础设施
js/mod-*.js           七个工具，一个文件一个工具
js/shell.js           路由 + 首页 + 工具宫格 + 设置
sw.js                 离线缓存
manifest.json         PWA 配置

cook/                 今天吃啥（早期做的做饭应用，保留可访问 /yb/cook/）
tools/                开发自检脚本（截图 / 布局探针 / 端到端测试 / 图标生成）
```

## 有哪些工具

| 工具 | 能干什么 |
| --- | --- |
| 待办 | 随手记、勾掉、自动沉到「已完成」 |
| 记账 | 3 秒记一笔，本月分类占比 + 按日流水 |
| 纪念日 | 生日、在一起、下次旅行，倒数或正数天数 |
| 日记 | 一天一句 + 心情 + 一张照片（照片自动压缩） |
| 打卡 | 自定义习惯，连续天数 + 近 28 天方格 |
| 经期 | 记开始日，自动算平均周期和下次时间 |
| 转盘 | 决定不了的时候转一下，选项可改 |

工具宫格上每个格子都显示**实时摘要**（比如「3 件事没做」「本月花了 ¥551.3」），不用点进去就知道状态。

## 几个刻意的设计决定

- **数据全部在本地**。没有服务器，所以不存在数据泄露；代价是换手机要手动备份（「我 → 备份到文件」导出一个 json）。
- **首页只做聚合，不重复功能**。今天要做的事、值得期待的日子、打卡进度、本月花销、日记入口，一屏看完。
- **每个工具有自己的主题色**，主按钮跟着页面变色，避免七个工具长得一模一样。
- **深色模式**只换 CSS 变量，跟随系统。

## 踩过的坑（改代码前值得知道）

1. **`.app` 上的 `overflow-x` 只能用 `clip`**。用 `hidden` 会把容器变成滚动层，里面所有 `position: sticky` 直接失效（底部常驻按钮会跟着滚走）。
2. **service worker 用 stale-while-revalidate，不能用 cache-first**。cache-first 会让线上更新永远到不了用户手机。
3. **`#view` 是常驻元素，事件必须用 `onclick =` 赋值而不是 `addEventListener`**，否则每次重绘都会多挂一个监听，点一次勾选会被触发多次（勾上又取消）。
4. **模块里的 `save()` 要把结果 `return` 出去**。调用方用 `if (!save(...)) return` 兜住存储写满的情况，不返回就等于永远提前退出（日记页踩过：数据存进去了但界面不更新）。
5. **headless 浏览器要加 `--no-proxy-server`**，否则这台机器的系统代理会让截图全是错误页。
6. **只改 hash 不会重新加载页面**，截图脚本里要先把页面导航到 `about:blank`。

## 开发

```bash
# 起本地服务器（浏览器里打开 http://127.0.0.1:8765/）
python -m http.server 8765 --bind 127.0.0.1

# 逐屏截图，产出在 _shots/
node tools/shot.js

# 量某个页面各层容器的真实尺寸（排查布局问题用）
node tools/probe.js "http://127.0.0.1:8765/index.html#/t/bill" ".view,.pad,.dock"

# 端到端功能自测：真的点一遍，检查 localStorage 里的数据对不对
node tools/test.js

# 重新生成 PWA 图标（零依赖，Node 内置 zlib 直接编码 PNG）
node tools/make-icons.js
```

`tools/test.js` 目前 **39 项断言**，覆盖每个工具的增删改、边界情况（金额为空不保存、同一天不重复记经期）、弹层与路由交互、横向溢出、运行时报错。
