# 今天吃啥

一个只干两件事的小应用：**帮她决定今天吃什么**，然后**把要买的菜列成清单**。

纯前端，无后端、无登录、无账号。数据存在手机本地，超市里没信号也能用。

---

## 它解决的到底是什么

每天下班，最难的不是做饭，是「今天吃什么」这个决定，以及到了超市想不起要买啥。

所以这个应用只有一条主线：

```
摇一道菜  →  食材自动进清单  →  按货架顺序逛超市  →  勾掉买完的
```

没有别的功能。第一版就砍到这个程度。

---

## 功能

**今天吃啥**
- 32 道家常菜随机推荐，不满意就「换一道」
- 按口味筛：15 分钟内 / 素的 / 有肉 / 汤 / 主食 / 辣 / 清淡
- 自动避开最近做过的菜，不会连着吃重复
- 点「就它了」，食材直接进清单

**菜谱库**
- 每道菜都有完整食材、用量、分步做法和小提示
- 可以搜菜名，也可以搜食材（比如搜「番茄」）
- 可以加自己的菜，食材分类会自动猜

**买菜清单**
- 按超市动线分组：蔬菜 → 肉蛋 → 主食 → 其他 → 调料
- 多道菜的相同食材自动合并用量（`鸡蛋 3 个 + 2 个`）
- 勾选即划掉并沉底，顶部有进度
- 调料默认不入清单（家里常备），需要时可一键带上
- 一键复制清单，直接发微信让人代买

## 本地跑起来

不需要安装任何依赖，一个静态服务器就够：

```bash
python -m http.server 8765
# 或 npx serve .
```

打开 `http://localhost:8765`。

> 手机上调试：电脑和手机连同一个 WiFi，用 `http://<电脑内网IP>:8765` 访问。

## 部署到手机（GitHub Pages）

仓库已推送后，在 GitHub 仓库里：

1. **Settings → Pages**
2. Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`
4. 保存，等一两分钟

访问地址：`https://gatsbyoo.github.io/yb/`

**加到手机主屏幕**
- iPhone（Safari）：分享 → 添加到主屏幕
- 安卓（Chrome）：⋮ → 添加到主屏幕 / 安装应用

加完之后就是一个独立图标的全屏应用，和原生 App 手感一样。

## 数据存在哪

全部在 `localStorage`，键名以 `yb.` 开头：

| 键 | 内容 |
| --- | --- |
| `yb.list.v1` | 当前买菜清单 |
| `yb.recent.v1` | 最近做过的菜（用于去重） |
| `yb.custom.v1` | 自己添加的菜谱 |
| `yb.filter.v1` | 上次选的口味筛选 |

**注意**：数据只在这台手机上。清除浏览器数据会清空清单和自定义菜谱（内置的 32 道菜不会丢，它们在 `js/data.js` 里）。

## 目录结构

```
index.html          页面骨架（三页 + 底部标签栏 + 抽屉）
css/style.css       设计系统与全部样式
js/data.js          32 道菜的菜谱数据
js/app.js           全部交互逻辑与本地存储
js/../manifest.json PWA 配置
sw.js               离线缓存（stale-while-revalidate）
icons/              应用图标（脚本生成，非手工绘制）
tools/              开发自检脚本
```

---

## 关于离线缓存

`sw.js` 用的是 **stale-while-revalidate**，不是 cache-first：

- 有缓存立刻返回 → 超市里没信号也是秒开
- 后台同时拉新版本写回缓存 → 下次打开就是最新的

用 cache-first 的话，改了代码用户永远收不到更新。这个坑踩过一次。

## 开发自检脚本

改完代码想确认没做坏，按顺序跑：

```bash
python -m http.server 8765     # 另开一个终端

node tools/test.js             # 端到端跑主流程，18 项断言
node tools/shot.js             # 六个页面截图到 _shots/
node tools/probe.js            # 量真实布局，抓横向溢出和 JS 报错
node tools/make-icons.js       # 重新生成图标
```

依赖：Node 18+，以及本机的 Edge 或 Chrome（截图用）。这些脚本不参与构建，删掉也不影响应用运行。

## 想改点什么

- **加菜**：直接改 `js/data.js`，格式照抄，`ing` 是 `[名称, 用量, 分类]`，分类只能是 `蔬菜/肉蛋/主食/其他/调料`
- **改配色**：`css/style.css` 顶部的 `:root` 变量
- **改文案**：搜索 `index.html` 里的文字

改完记得把 `sw.js` 里的 `CACHE = 'chisha-v2'` 版本号 +1，能更快让已安装的手机更新到新版。
